RSpace 2.24/1.124 is the last RSpace version running on Tomcat 9, version 2.25/1.125 is [migrated to Spring 6](../DeveloperNotes/UpgradingToSpring6.md) and therefore requires Tomcat 10.

If you were running RSpace on Ubuntu 22/Tomcat 9 setup, we recommend upgrading to Ubuntu 24 which 
comes with Tomcat 10 by default.

We plan to update this doc with more details, but for now if you need help with migrating Ubuntu or Tomcat,
please contact [support@researchspace.com](support@researchspace.com).
